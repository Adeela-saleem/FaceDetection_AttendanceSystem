Everything needed for daily attendance

Built for institutes that want accurate attendance without paper registers or manual roll calls.

📷

Face-recognition attendance

Use the live browser camera or upload a class photo. Every recognised face is matched to a registered student. In live mode the same face must be confirmed in several scans in a row before it is saved.

🏫

Sections & class timings

Group students into sections with a class start and end time. Attendance opens shortly before class begins and closes when it ends, so late scans are not saved by mistake.

🔐

Admin & Teacher roles

Admins manage everything. Teachers see students and records only for the sections assigned to them, and can remove only the attendance they created.

🗂

Records & CSV export

Filter attendance by date, student and section, add a manual entry when needed, and download the result as a CSV file for reports.

📊

Live dashboard

See who is present and absent today, section-wise progress, and a 14-day trend at a glance.

🛡

Secure by design

Hashed passwords, protected sessions, login attempt limits, permission checks on every request and an activity log for admins.

How it works

Three simple steps from setup to daily use.

  1. Register students

    An Admin adds each student with a few clear photos and places them in a section.

  2. Assign teachers

    The Admin creates Teacher accounts and assigns them to the sections they teach.

  3. Take attendance

    A Teacher selects a section, starts the camera or uploads a photo, and attendance is recorded automatically.

Two roles, clear permissions

Admin has full access. Teachers work only inside their assigned sections.
